Clash Path — Admin dữ liệu

Công cụ riêng để cập nhật ảnh + nội dung Roadmap TH1-18 cho web app. Chạy độc lập, không cần server, không cần đăng nhập.

Dữ liệu chỉnh ở đây lưu tạm trong trình duyệt (localStorage) để không mất khi tắt trang. Khi xong, bấm "Xuất imageMap.ts" / "Xuất townHallData.ts" rồi lưu đè file tải về vào đúng vị trí trong project web app: src/imageMap.ts và src/townHallData.ts. Danh sách item ở tab Ảnh khớp với src/upgradeData.ts tại thời điểm xuất bản công cụ này — nếu sau này bạn thêm item mới trong upgradeData.ts, dùng nút "Nhập JSON sao lưu" với 1 file catalog mới, hoặc báo lại để cập nhật danh sách.
